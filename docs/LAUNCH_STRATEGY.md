## 5. 첫 100명 — 친구 주도 유입 계획 (가설)

제품의 성장 메커니즘은 확정돼 있다(SESSION_HANDOFF §0): **릴스 업로드 → 낯선 사람이 봄 → 관심 → 매칭**. 광고 없음. 유입 단위는 "캠페인 1개 = Introducer 1명 + Dater 1명".

1. **시드 10 캠페인(9/11~9/20)**: 소유자의 실제 지인 네트워크에서 Introducer 10명 모집. 각자 친구 1명을 피치. 조건: 실명 아닌 표시 이름, 사진 동의, Dater 웹 승인. Claude가 하는 일: 창작 가이드 문안, 녹음 팁(30~60초, 12단어 이상), 승인 링크 안내 템플릿.
2. **릴스 20개(9/20~9/30)**: 캠페인당 MP4 1~2개(엔드카드에 페이지 주소). 채널은 소유자 계정 + Introducer 본인 계정. 캡션은 `?src=creator-kit` 어트리뷰션 유지.
3. **전환 관찰 지표(§6)**: 릴스 조회 → `reel_visit` → `s1_intent_created` → `interest_submitted` → `interest_accepted` → `intro_room_created`.
4. **100명 정의**: 관심을 보낸 시청자 100명(가입 완료). 이 숫자는 가설 검증용 문턱이지 약속이 아니다.

하지 않을 것: 유료 광고, 인플루언서 지급, 대량 초대 메일(waitlist 1행뿐이며 초대 발송은 앱 출시 당일 1통 원칙).
